## how to convert function to lambda

-   remove access modifier
-   remove return type 
-   remove method name 
-   add -> 

-   additionally
    -   remove types
    -   remove return keyword

-   Functional interfaces can hold lambda expressions 
-   Using lambda expressions we don't need an additional implementation class for the interface 
-   A functional interface should have only one method to create a lambda expression 
-   we have many predefined interfaces where we can use lambda expressions

## Functional Interface

Interface having exactly single abstract method but can have any number of default and static methods. we can invoke lambda expression by using functional interfaces
