## ClassPath

scratch/prof/src> java Test

The above path is called class path -> java searches for the class Test from this path

if package of Test is `package test;`
java searches for test/Test.class in the class path (scratch/prof/src>)

## ClassName

A file can have multiple classes , but the public class needs to be same as the file name.

## Package

package is just the directory , the class should be present in the same directory structure as defined as package
